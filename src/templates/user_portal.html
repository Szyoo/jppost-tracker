Bark 设置手顺

01
配置服务器地址

在 iPhone / iPad 上安装 Bark，把服务器地址设为 {{ bark_help.public_url or bark_help.internal_url or '未配置' }}。

02
复制推送 URL 或 key

打开 Bark 后复制测试推送 URL。你可以把整条 URL 直接粘贴到 `Bark Keys`，系统会自动提取 key。

03
需要多端时逐个登记

每个设备都有自己的 key。想让同一条消息同时推送到多个终端，就把多个设备的 key 一行一个填进去。

04
保存并测试

你可以直接点“发送 Bark 测试”，预览当前参数的实际效果。若只想看服务在线，可访问 {{ bark_help.public_url }}{{ bark_help.health_path }}。

注意：同一个 Bark key 对应的是一个已注册设备。多端推送不是“一个 key 自动广播到所有设备”，而是需要把多个设备各自的 key 都填进来。
